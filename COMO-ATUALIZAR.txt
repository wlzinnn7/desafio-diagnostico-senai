DESAFIO DE DIAGNÓSTICO – SENAI-MG – ATUALIZAÇÃO V4

MELHORIAS
- 20 questões revisadas, com enunciados mais diretos e quatro alternativas de comprimentos próximos.
- A resposta correta não é sempre a maior: há 5 respostas corretas em cada uma das letras A, B, C e D.
- Pontuação usa timestamp do Firebase em milissegundos e mostra 3 casas decimais.
- Acerto vale de 100,000 a 200,000 pontos conforme tempo de resposta; 5 rodadas sorteadas valem 2×.
- Revelação automática pelo painel do apresentador quando TODOS os participantes registrados responderem,
  ou após os 30 segundos. MANTENHA O PAINEL DO APRESENTADOR ABERTO durante a partida.
- Botão "ENCERRAR PARTIDA" para o apresentador, com confirmação. Se houver rodada em andamento,
  somente respostas já enviadas nessa rodada são pontuadas; o pódio aparece para todos.
- Controle das rodadas com transações do Firebase para evitar pontuação duplicada.
- Ranking TOP 3 e suporte a celular mantidos.

ATUALIZAR PELO GITHUB (SEM INSTALAR NADA)
1. Abra: https://github.com/wlzinnn7/desafio-diagnostico-senai
2. Clique em Add file > Upload files.
3. Extraia o ZIP e envie SOMENTE: index.html, app.js, questions.js e style.css
4. Confirme a substituição dos arquivos com Commit changes.
5. Aguarde o GitHub Pages publicar (aba Actions).
6. No computador, atualize com Ctrl + Shift + R; no celular, feche e reabra a aba.
7. Abra uma SALA NOVA para que o modelo de partida não misture versões diferentes.

IMPORTANTE
- Não altere nem substitua o firebase-config.js. Os quatro arquivos do ZIP o reutilizam.
- As regras do Realtime Database já configuradas são compatíveis com a estrutura do jogo.
- Testado com dados simulados: respostas em 1ms, rodada 2×, revelação automática,
  fim antecipado, pódio e layout em 390 pixels; ainda é preciso testar no Firebase real.
- Como os arquivos JS são públicos, esta aplicação é apropriada para atividade educativa supervisionada,
  não para competição formal com prêmios de valor.
